# Reference Documentation

This section contains technical descriptions and detailed information about ecto_shorts.

Reference documentation is information-oriented and designed to help you understand the specifics of ecto_shorts components.

## Module Documentation

Detailed API documentation for each module is automatically generated from the source code and available through ExDoc:

### Main Modules

- `EctoShorts.Actions` - Functions for CRUD operations
- `EctoShorts.CommonChanges` - Functions for handling associations in changesets

### Support Modules

- `EctoShorts.CommonFilters` - Functions for converting parameter maps to Ecto queries
- `EctoShorts.SchemaHelpers` - Utility functions for working with Ecto schemas

### Query Builder Modules

- `EctoShorts.QueryBuilder` - Functions for building Ecto queries
- `EctoShorts.QueryBuilder.Schema` - Schema-related query building functions
- `EctoShorts.QueryBuilder.Common` - Common query building functions
