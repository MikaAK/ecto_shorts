# Tutorials

This section contains step-by-step lessons to help you learn ecto_shorts from the ground up. These tutorials follow the [Diataxis framework](https://diataxis.fr/) principles, focusing on practical, hands-on learning.

Tutorials are learning-oriented and designed to teach you how to use ecto_shorts through practical examples. They guide you through building real applications while explaining key concepts along the way.

## Available Tutorials

### [Getting Started with ecto_shorts](./getting-started.md)

A beginner-friendly introduction to ecto_shorts that covers:

- Setting up ecto_shorts in a Phoenix project
- Creating schemas that work well with ecto_shorts
- Building context modules with the Actions API
- Performing basic CRUD operations
- Using CommonFilters for simple queries

**Time to complete:** Approximately 20-30 minutes

### [Building a Complete Application](./complete-application.md)

A more comprehensive tutorial that builds a blog application with multiple related schemas:

- Setting up schemas with associations (users, posts, comments)
- Creating context modules for related schemas
- Working with preloaded associations
- Building a JSON API with Phoenix controllers
- Implementing advanced filtering and search
- Creating records with nested associations

**Time to complete:** Approximately 45-60 minutes

## What's Next

After completing these tutorials, you'll have a solid understanding of how to use ecto_shorts in your applications. For more detailed information, check out the [Reference](../reference/index.md) section, and for deeper understanding of concepts, see the [Explanation](../explanation/index.md) section.
